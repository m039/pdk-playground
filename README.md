# Various Examples with Padauk MCU

In this repository, you can find various examples which are using [pdk-platformio](https://github.com/m039/pdk-platformio).

1. [Blink](Code/1%20Blink) - basic example of blinking a led
2. [BlinkAsm](Code/2%20BlinkAsm) - the same, but in assembler
3. [Led PWM](Code/3%20Led%20PWM) - basic example of using PWM for fading a led
4. [Musical Melody (Period Mode)](Code/4%20Musical%20Melody%20(Period%20Mode)) - a project contains code that plays mostly Russian melodies on a buzzer
5. [Musical Melody (PWM Mode)](Code/5%20Musical%20Melody%20(PWM%20Mode)) - a project for testing adjusting volume by changing PWM signal
6. [PMS150C-I2C-1Bit ADC](Code/6%20PMS150C-I2C-1Bit%20ADC) - 1-bit comparator ADC voltage meter with an I2C slave interface and companion Arduino Nano master monitor (tested on PFS154, optimized to fit PMS150C)
